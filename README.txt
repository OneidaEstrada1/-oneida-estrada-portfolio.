ONEIDA ALEXANDRA ESTRADA AYALA — PORTFOLIO

FILES
- index.html: portfolio structure and content
- styles.css: visual design and responsive layout
- script.js: mobile navigation and scroll progress

HOW TO OPEN
1. Extract the ZIP into a folder.
2. Keep all three files together in the same folder.
3. Open index.html in your browser.

The portfolio uses a new editorial layout while preserving the lavender, purple, and soft pink color palette. The portrait is embedded in index.html.
